# 💫 About Me:
Mohit Chogale is a Computer Science & Electronics Engineering student at St. John College of Engineering and Management, Mumbai, building across full-stack development, applied AI/ML, and blockchain. His recent work includes an AI-powered incident intelligence platform (Python, FastAPI, Redis, PostgreSQL), a full-stack customer support CRM, and EthVote, a decentralized voting application on Ethereum. He has interned as a System Engineer at System Controls Pvt. Ltd. and as a Blockchain & Cyber Security intern at IOFT, and holds certifications in Machine Learning, Solidity, and Web3 development. He's currently exploring opportunities in software development, AI/ML engineering, and blockchain.
